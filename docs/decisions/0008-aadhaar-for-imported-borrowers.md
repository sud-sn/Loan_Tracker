# 0008 · Aadhaar for imported borrowers

**Status:** accepted · PRD §3 (Aadhaar required) vs §15 (100-loan import from a notebook)

Aadhaar stays required for every borrower added in the app. The notebook import may leave it empty:
such borrowers are marked **Details missing**, and **no new loan** can be given to them until the
number is added. Their imported loans and payments are saved normally.
