# Tamil glossary

The words used across the app, receipts and reminders. Plain, everyday Tamil is preferred over formal
words (PRD section 9). **To be reviewed by a native speaker before launch.**

| English | தமிழ் | Notes |
| --- | --- | --- |
| Loan | கடன் | |
| Loan amount | கடன் தொகை | |
